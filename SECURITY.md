# Security Policy

## Reporting a vulnerability

Do not open a public issue for a security vulnerability.

Report privately through GitHub Security Advisories on the affected repository:
`https://github.com/miguelarios/<repo>/security/advisories/new`

If the repository has advisories disabled, or you are unsure which repo is
affected, use https://github.com/miguelarios/.github/security/advisories/new

## What to include

1. Affected component and version or commit
2. Impact — what an attacker gains
3. Reproduction steps
4. Any suggested remediation

Reports without reproduction steps and demonstrated impact will be deprioritized.

## Scope

These are personal and homelab projects maintained by one person. There is no
bounty program and no response-time guarantee, though I read reports promptly.
